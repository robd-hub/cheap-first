How it decides

  1. On device first. Firebase AI Logic runs the question on Gemini Nano in Chrome. If this device has no model, Firebase sends it to a small cloud model instead, and you see that.
  2. Check the answer. For a number or a multiple-choice answer, a second local answer solved from scratch has to agree, and any equation has to add up. For anything else, code looks for warning signs, then a judge scores it: Gemini Nano in Budget and Balanced, a small cloud model in Strict.
  3. Escalate only when needed. Below the pass mark (Budget 60, Balanced 75, Strict 85) a stronger Gemini model answers in the cloud. You can see both answers.

When the answer stays on this device, your question never leaves it. When it goes to the cloud, it is sent to Google's Gemini API through Firebase. Only counts are stored, never questions or answers. A small model judging open questions misses things: on number and choice questions the check is code and a second answer, which a model can't rubber-stamp.
